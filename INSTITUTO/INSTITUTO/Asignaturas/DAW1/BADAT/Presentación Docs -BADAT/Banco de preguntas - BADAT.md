2. **Definición de Informática. Razónala.**
>"Ciencia que tiene por objeto el tratamiento automático de la información". Lo que entiendo por esta definición es que la informática es una ciencia que busca el tratamiento automático de la información trabajando con objetos inteligentes.
3. **¿Qué resulta fundamental a la hora de administrar los datos? Razónalo.**
>Los Sistemas de Información, porque se encarga de gestionar y administrar la información, de una manera óptima y eficaz.
4. **Define Sistema de Información. Razona la definición.**
>Un Sistema de Información es la serie de pasos que se encarga de gestionar y administrar la información. Ya sea un proceso humano de organización o un software que tiene una empresa.

6. **Describe los componentes de los sistemas de información.**
>- Recursos físicos -> Es básicamente todo el harware necesario para almacenar y procesar los datos
>- Recursos lógicos -> Es el conjunto de herramientas software que nos ayuda a almacenar, manipular, procesar o enviar datos/información.
>- Recursos humanos -> Son las personas que administran o gestionan los datos
>- Normas y protocolos -> Son normas de un Sistema de Información, tanto para el hardware como el software, como para los propietarios de dicho SI de una empresa.

8. **Indica y explica los objetivos de los sistemas de información. Explica porqué no tiene sentido un SI si no se alcanzan los objetivos.**
> - Mejorar la gestión empresarial (eficiencia) minimizando el esfuerzo y maximizando los resultados.
> - Obtención de la información deseada en tiempo real.
> - Facilitar las actividades de organización y planificación de la empresa.
> - Facilitar la toma de decisiones, obteniendo resultados incluso a priori.

>EXPLICACIÓN:
>Considero que si un SI no cumple con ninguno de estos objetivos lo que tenemos es una gestión de archivos y datos clásica, en la que todos esos objetivos dependían del ser humano. Los Sistemas de Información nacieron para mejorar y facilitar el uso, la gestión y organización de datos, si no cumple con esos objetivos, no cumple con los requisitos mínimos para realizar sus funciones.
