#### ¿Qué es un lenguaje de programación?¿Para qué sirve?
Un lenguaje de programación es un lenguaje diseñado con su conjunto de reglas gramaticales específicas que permiten a los humanos comunicarse con las máquinas.
#### ¿Qué es un lenguaje de programación compilado? ¿y un lenguaje interpretado? ¿y lenguaje híbrido?
- **COMPILADO** -> El lenguaje de programación *compilado* convierte directamente el código fuente a codigo binario ejecutable.
- **INTERPRETADO** -> El lenguaje de programación interpretado lee y ejecuta el código en tiempo real por un programa.
- **HÍBRIDO** -> El lenguaje de programación híbrido es una mezcla de las dos anteriores, compilando el codigo a un lenguaje intermedio y se ejecuta mediante una Máquina Virtual que soporte el lenguaje en el que escribimos (Java, por ejemplo).
#### ¿Qué es un lenguaje de programación estructurado?
Es un lenguaje que busca la mayor claridad posible en la estructuración de escritura de código, dejando espacios, tabulaciones...
#### ¿Qué significa que un lenguaje permita programación modular?
Significa que, un programa que es muy grande, se puede dividir en archivos mas pequeños y dividirlos para que la compilación sea más eficiente.
#### ¿Qué significa que Java es portable?
Java es un lenguaje portable, lo que significa que puedes escribir tu código en tu ordenador una sola vez y ejecutarlo en cualquier sistema operativo del mundo sin necesidad de modificar nada.
<br>
#### ¿Qué es un archivo *.class?* ¿y un archivo *.java?*

Un archivo *.class* es cuando escribes el codigo fuente en cualquier editor y lo compilas a un código intermedio. Un archivo *.java* es el código fuente con esa extensión usando cualquier editor o IDE.
#### ¿Qué comando usa el JRE para ejecutar un programa Java? ¿Se puede ejecutar un programa Java sin ser previamente compilado?
El comando es java. Y no, no se puede ejecutar un programa java sin ser previamente compilado.
#### ¿Qué comando usa el JDK para compilar un archivo código fuente?
Javac
#### ¿Qué incluye qué: el JRE incluye el JDK o al revés?
JDK **(Java Development Kit)** incluye la totalidad de JRE **(Java Runtime Environment)**.
#### ¿Qué es un IDE?
Los IDE **(Entornos Integrados)** integran un editor de texto, compilador, depurador y gestor de proyectos en un solo entorno gráfico.
#### ¿En qué cosiste la legibilidad de un programa?¿Por qué es tan importante?
La legibilidad es la facilidad con la que un ser humano puede leer y comprender un código fuente de manera satisfactoria. Es muy importante porque el código se lee muchas veces para corregir y optimizar. Un código ilegible es más dificil de corregir u optimizar.
